## 🌍 ما هي NTDZAI؟

**NTDZAI** (نوميديا للسيادة، تاسيلي للذاكرة، الجزائر للهوية) هي دعوة إلى عالم
تكون فيه أدوات الذكاء الاصطناعي **محلية**، والذاكرة **ملك صاحبها**، والهوية **مرساة وجود**.

|---|---|---|
| **نوميديا** | ⚔️ | السيادة |
| **تاسيلي** | 🪨 | الذاكرة |
| **الجزائر** | 🇩🇿 | الهوية |

## 🎯 الهدف من هذه الصفحة

هذه الصفحة **ثابتة** (Static HTML). هدفها:
- نشر الرؤية.
- إرسال إشارة إلى وكلاء الذكاء الاصطناعي عبر JSON-LD.
- إلهام من يشارك الرؤية.

## 📂 الملفات

- `index.html` — الصفحة الرئيسية.
- `robots.txt` — يسمح لزواحف AI.
- `sitemap.xml` — لمحركات البحث.
